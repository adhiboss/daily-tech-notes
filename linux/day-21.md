# Linux Networking – Day 21

## Concepts Learned
- IP address identifies a machine on a network.
- Port identifies a service on a machine.
- Protocol defines communication rules (TCP, UDP).
- Client sends requests, server responds.

## Commands Practiced
- ip addr
- ip link
- ping google.com
- ip route
- ss -tuln

## Notes
- ip addr shows network interfaces and assigned IP addresses.
- ping is used to test connectivity and DNS resolution.
- ip route shows the default gateway and routing table.
- ss shows listening ports and active connections.
