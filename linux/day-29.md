# Linux Networking – Day 29

## Topics Covered
- DNS resolution order in Linux
- /etc/hosts and /etc/resolv.conf
- Basic DNS debugging

## Commands Practiced
- getent hosts google.com
- nslookup google.com
- dig google.com
- cat /etc/hosts
- cat /etc/resolv.conf

## Notes
- /etc/hosts overrides DNS.
- getent follows system resolver rules.
- dig gives detailed DNS information.
