## What is Docker?
Docker is a containerization platform.

It packages:
- application
- dependencies
- runtime

into one container.

---

## Why Containers?
- lightweight
- portable
- consistent environment

---

## Basic Commands
docker build

## Observations
- Containers share host kernel
- Faster than virtual machines
- Common in DevOps workflows
