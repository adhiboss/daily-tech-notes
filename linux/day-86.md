# Day 86
## Focus
CI/CD Basics

## What is CI?
Continuous Integration:
Automatically test and merge code changes.

## What is CD?
Continuous Deployment/Delivery:
Automatically deploy after successful testing.

---

## CI/CD Pipeline Steps
- code push
- build
- test
- deploy

## Tools
- GitHub Actions
- Jenkins
- GitLab CI

- CI/CD improves development speed
- Reduces manual deployment errors
