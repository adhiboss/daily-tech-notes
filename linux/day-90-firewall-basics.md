# Day 90 - Linux Firewall Basics

## What is a Firewall

A firewall controls incoming and outgoing network traffic based on security rules.

---

## Common Linux Firewalls

- iptables
- nftables
- ufw (Ubuntu firewall)

---

## Check Firewall Status

sudo ufw status

---

## Allow SSH

sudo ufw allow 22

---

## Allow HTTP

sudo ufw allow 80

---

## Enable Firewall

sudo ufw enable

---

## Why It Matters

Firewalls protect servers from unauthorized network access.
