## What is Nginx?
Nginx is:
- web server
- reverse proxy
- load balancer

---

## Uses
- serve static files
- reverse proxy backend
- SSL termination
- load balancing

---

## Common Config Location

## Observations

- Common in production
- Often used with Node/Python backends
