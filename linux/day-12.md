# Linux – Day 12

## Commands Practiced
- df -h
- du -sh
- free -h
- top

## Notes
- df -h shows disk usage in human-readable form.
- du -sh shows folder size.
- free -h shows memory usage.
- top shows live system performance.
## Extra 1
- Practiced checking disk space with df -h.
## Extra 2
- Used du -sh to measure folder sizes.
## Extra 3
- Reviewed memory stats using free -h.
