# Linux Networking – Day 28

## Topics Covered
- Client–server communication model
- Local networking using netcat (nc)
- Review of IP addresses, ports, and protocols
- Basic troubleshooting steps for connectivity issues

## Commands Practiced
- ip addr
- ss -tuln
- nc -l 8080
- nc localhost 8080
- ping google.com
- curl http://example.com

## Notes
- netcat can be used to simulate a basic TCP server and client.
- IP + Port together identify a network service.
- ss helps verify which services are listening on which ports.
- ping helps test basic network connectivity.
- curl tests HTTP communication with a server.
