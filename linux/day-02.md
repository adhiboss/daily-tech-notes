# Linux – Day 02

## Commands Practiced
- mkdir
- rmdir
- touch
- rm

## Notes
- mkdir creates directories
- touch creates empty files
- rm deletes files (use carefully)

### mv
Moves or renames files.

## cp
Copies files or folders.


---

## Key Notes
- `rm -r` deletes folders **permanently**
- Linux has **no recycle bin** in terminal
- Always double-check before using `rm`
