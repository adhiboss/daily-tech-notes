## Topics Learned

- chmod command (symbolic and numeric modes)

## Commands Practiced
- ls -l
- chmod +x script.sh
- chmod 644 file.txt
- chown user file.txt
- chgrp group file.txt

## Key Concepts
- r = 4, w = 2, x = 1
- 755 → owner: rwx, group: r-x, others: r-x
- 644 → owner: rw-, group: r--, others: r--
