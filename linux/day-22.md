# Linux Networking – Day 22

## Concepts Learned
- IP address identifies a machine on a network.
- Port identifies a service on a machine.
- Protocol defines communication rules.
- TCP is reliable, UDP is fast but unreliable.

## Commands Practiced
- ip addr
- ss -tuln
- curl http://example.com
- getent hosts google.com

## Notes
- IP + Port together identify a network service.
- ss shows which services are listening on which ports.
- curl is used to test HTTP communication.
- DNS resolves domain names to IP addresses.
