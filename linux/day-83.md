## Focus
Microservices Architecture Basics

## What are Microservices?
Microservices is an architecture where applications are split into small independent services.

Each service:
- has its own logic
- can be deployed separately
- communicates via APIs

---

## Advantages
- easier scaling
- independent deployment
- fault isolation

---

## Challenges
- complex networking
- service discovery
- monitoring

---

## Observations
- Works well with containers
- Requires strong API design
